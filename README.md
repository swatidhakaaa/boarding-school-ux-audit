# 🎓 Interactive Boarding School Website & UX Audit Suite

An interactive front-end web application showcasing a responsive prototype of a premier residential boarding school website alongside a live **UX & Technical Audit Dashboard**. Built to demonstrate real-world UI/UX evaluation, mobile responsiveness testing, and interactive flaw resolution.

🔗 **Live Demo:** [View Live Project](https://your-username.github.io/boarding-school-ux-audit/)

---

## ✨ Key Features

* **📱 Real-Time Device Viewport Switcher:** Seamlessly toggle between full **Desktop View** and a simulated **Mobile View (375px)** to evaluate layout adaptability and navigation collapse.
* **🔍 Interactive UX Audit Inspector:** A dedicated side-drawer featuring scorecard meters and evaluations for *Site Structure*, *Mobile Responsiveness*, and *Page Load Performance*.
* **🎯 Visual Flaw Highlighter:** Clicking audit insights dynamically highlights real-time UI/UX issues on the mockup (such as heavy hero assets and micro touch-target close buttons).
* **🛠️ Live UX Solution Sandbox:** Test instant UI improvements in real time—expand cramped 24px modal close buttons to accessible **44px+ touch targets**, or replace intrusive full-screen pop-ups with a sleek **sticky bottom admissions drawer**.

---

## 🛠️ Tech Stack

* **HTML5** – Semantic markup and accessible structure
* **Tailwind CSS** – Utility-first styling, responsive grids, and custom theme colors
* **Vanilla JavaScript** – DOM manipulation, state management, and interactive sandbox controls
* **FontAwesome & Google Fonts** – Typography (`Playfair Display` & `Inter`) and UI icons

---

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Open the project folder in **Visual Studio Code**.
3. Open `index.html` directly in any browser or run it using the **Live Server** extension.
