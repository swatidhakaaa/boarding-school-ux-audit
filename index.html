1. Site Structure & Navigation

7 Main Navigation Items: About Us, Academics, Admissions, Pastoral Care, Beyond Classroom, News & Events, Contact.

Highly logical grouping for prospective parents seeking fee tiers & eligibility vs current parents accessing academic schedules.

2. Mobile Responsiveness

Layout collapses effectively into a sticky mobile hamburger menu (). Key CTAs remain accessible.

3. Page Load & Performance

Fast core render, but heavy high-res hero images (e.g. 1920px campus photos) slow down First Contentful Paint on mobile 3G/4G networks.

4. Key UX & Technical Flaws

Micro Modal Close Button Mobile Touch

Modal popup close button () is only 24px×24px, violating Apple/Android touch target guidelines (min 44px×44px).

Modal Interruption Friction Conversion UX

Full screen popup obstructs research phase for first-time parent visitors.

5. Proposed UX Solution & Sandbox

Test live UX fixes on the mock website:

Fix Touch Target Size
Expand modal close button to 44px
Replace Pop-up with Sticky Bar
Non-intrusive bottom drawer CTA
